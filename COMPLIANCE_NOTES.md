# SPbU compliance changes

Implemented:

- RU/EN AI Policy pages.
- RU/EN Personal Data Policy pages.
- The Personal Data Policy page includes:
  - general privacy information;
  - consent to processing data submitted through web forms;
  - consent to processing data collected via metric programmes.
- Personal Data Policy link added to the footer.
- SPbU founder logo added to the header.
- Copyright notice added to the footer with automatically generated current year.
- Cookie consent banner added to all pages.
- Cookie consent is stored for one year.
- The cookie banner links to the Personal Data Policy page.
- Base site URL changed to https://diffjournal.spbu.ru.

Not implemented:

- No new personal-data collection forms were created because the current
  journal project does not contain a form requiring such collection.
- If such forms are added later, they must be hosted in the SPbU domain and
  include a mandatory checkbox linking to the Personal Data Policy page.
- No Yandex.Metrica or other analytics service was added by this change.
  The supplied consent text mentions Yandex.Metrica, but analytics should
  only be enabled according to the actual SPbU infrastructure/configuration.
