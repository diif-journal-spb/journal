Аннотация. Предложен итерационный алгоритм совместного поиска матриц функции 
Ляпунова и обратной связи в задачах квадратичной стабилизации линейных стационарных 
систем при частично измеряемом векторе состояния. В основе алгоритма лежит 
линеаризация билинейных слагаемых матричного неравенства и поиск двух взаимно 
обратных матриц. Доказана сходимость числовой последовательности, порождаемой 
алгоритмом. Испытание алгоритма выполнялось на полностью управляемых и полностью 
наблюдаемых линейных системах, сгенерированных случайным образом. Дополнительно 
показано применение алгоритма для решения задачи стабилизации двухзвенного 
перевернутого маятника с помощью динамической обратной связи. 
 
Ключевые слова: матрица функции Ляпунова, квадратичная стабилизация, обратная связь, 
билинейные матричные неравенства. 
 
1. Введение и постановка задачи 
 
Задача стабилизации линейных систем на основе широко применяемого в современной теории 
управления метода квадратичных функций А.М. Ляпунова сводится к решению матричного 
неравенства относительно положительно определённой матрицы и стабилизирующей матрицы

5. Заключение 
 
В статье предложен итерационный алгоритм решения билинейных матричных неравенств, 
возникающих в задаче квадратичной стабилизации линейных стационарных систем в условиях 
частично измеряемого вектора состояния. Особенность алгоритма состоит в том, что выполняется 
совместный, а не раздельный поиск матриц функции Ляпунова и обратной связи. В основе 
алгоритма лежит линеаризация билинейных слагаемых исходного матричного неравенства. 
Условие существования двух взаимно обратных матриц записывалось с помощью спектральной 
нормы вспомогательной линеаризованной матрицы. Введен дополнительный скалярный 
параметр, позволяющий управлять скоростью сходимости числовой последовательности. Итоги 
испытания алгоритма показали, что относительная доля задач с успешным завершением близка 
к единице. По поиск решения затрачивалось в среднем не более восьми итераций.

An algorithm for the joint finding matrices of the Lyapunov function 
and feedback in linear systems quadratic stabilization problems

Abstract. An algorithm for the joint finding matrices of the Lyapunov function and feedback 
in quadratic stabilization solving problems of linear time-invariant systems with a partially 
measurable state vector is proposed. The basis for the algorithm is the bilinear matrix inequalities 
linearization and two mutually inverse matrixes finding. It is proved that the numerical sequence 
generated by the algorithm is converged. The algorithm testing is performed on completely 
controlled and completely observed systems, generated randomly. It is additionally shown the 
algorithm applying for the two-link inverted pendulum stabilization problem solving by the 
dynamic feedback. 
 
Keywords: Lyapunov function matrix, quadratic stabilization, feedback, bilinear matrix 
inequalities.
